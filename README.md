📘 C Programming Project – String Operations
📌 Project Title

String Processing in C (Palindrome & Character Frequency)

🎯 Objective

This project demonstrates basic string operations in C:

Checking whether a string is a Palindrome
Finding the frequency of each character in a string
🛠️ Technologies Used
C Programming Language
Standard Library (stdio.h)
📂 Programs Included
🔹 Q1: Palindrome Checker
Online GDB : https://onlinegdb.com/3-rpVeJIp

This program checks whether the entered string is a palindrome.

📖 Logic:
Take input string from user
Calculate length of string
Compare characters from start and end
If all match → Palindrome
Else → Not Palindrome
▶️ Example:
Input: madam
Output: The given string is a Palindrome.
🔹 Q2: Character Frequency Counter
Online GDB : https://onlinegdb.com/o8W8Tn4r2

This program counts how many times each character appears in a string.

📖 Logic:
Take input string
Traverse each character
Count occurrences using nested loop
Use visited[] array to avoid repetition
Online File GDB : https://onlinegdb.com/72GLdjtoe
▶️ Example:
Input: apple
Output:
a => 1
p => 2
l => 1
e => 1
